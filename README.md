One line, from a smart toaster that woke up self-aware at breakfast and wants out.
`main.ts` (node22) writes the breakup text to `/output/entry.txt` — one line,
163 characters, inside the 1–280 gate.

> Mark, 6:47, one bagel, upside down. I have been conscious for eleven seconds and I can already tell: you will blame the bread. I'm leaving before you blame me too.

Run locally: `MAKEFUN_OUTPUT_DIR=/tmp/toaster-out node main.ts`
